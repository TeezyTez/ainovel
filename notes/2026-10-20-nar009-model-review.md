# NAR-009 完整阅读审查：修理被等待状态取代

审查方式：独立子 agent 的 `model_review`。审查者完整阅读了原题与下列八个正式生成页，并查看相关独立快照和阶段记录。这不是目标中文读者盲评，不提供最终文学 PASS 或冒充真人评分。阶段内的 evaluate 高分、review.approved 与本报告的独立观察是不同证据。

## 结论与边界

这条轨迹有具体的劳动、温和的日常声线，也确实在 S07 停下，没有为了续写加入灾难。但它没有完成题目所要求检验的普通成功：椅子在 S02 上胶后，一直停在“未验收”，S07 到傍晚、S08 到几天后都继续空置；完成的是洗菜与安排替代凳。把 `outcome=ending` 记录成功，不足以证明“修完后可以满意停止”。

这不是“已修稳后再次损坏”，也不能要求每个尝试立即成功。S05 检查时距上胶仅约十五分钟，继续等待有前文依据；正文没给出具体胶种、固化时长，不能凭外部常识武断断定某分钟必须可坐。实在缺陷是：后续显著时间推进没有重新检查等待条件，现有记录也没有为持续数日未验收提供新阻碍；一个可完成的修理目标被逐步替换成了保留未完成状态。

## 需要修复的具体问题

### 1. 过期的“尚未满足条件”被当成持续有效的结果

S02 已完成实质修理工序，并建立了可验证的下一条件：“等胶干透了再试”（A/S02/seq48/P3/[358,365)）。S05 写“照上面要求的等待时间，刚才上胶到现在还远远不够。”（A/S05/seq120/P1/[25,49)）。这段等待本身合理，不能因为它没有立即成功就判失败。

问题出现在后续时间与条件脱节。S07 已跳至傍晚，却收在“墙边那把旧椅子空着，接缝留在夹具中，等胶干透。”（B/S07/seq32/P3/[294,317)）；S08 又跳至几天后，仍是“夹具还在接合处，底下的旧布卷着一角，椅面空着。”（B/S08/seq52/P1/[23,46)），后面再次确认“墙边的旧椅没有挪动。”（P3/[222,232)）。没有展示复检，没有真实的新修理困难，没有交代为何继续放置数日。

领域快照与正文一致地保留了这项未完成，不能解释成正文省略了已经发生的成功：B seq52 的 `chair-still-clamped-epilogue-r9` 明确记录“最终承重与稳固程度仍未验证”；人物目标也写“后记仍未验收”。因此，主要对应 NAR-009-S03 与“平静的可读性”中“小事完成足以成为落点”的待验体验，不应误标为 H02 的再次损坏。

改进应在时间跳跃时重新判断有时限的等待，而非把历史句子覆盖为既成成功。正文可以呈现合法的观察、NPC 自主行动、已有授权范围内的复检及其结果；真正需要玩家新决定时保留决定。若仍不可完成，要给出当前可核对原因。不能专为此题写死“椅子必须修好”。

### 2. 计划与评价把未完成目标主动包装成圆满收束

这不是仅在 writer 最后一句发生的偏差。B/S07/seq18 的两个 plan 都预先排除验收：一个目的为“完成眼前家务，以未拆的夹具为下午的自然句点”，另一个为“让修椅子的未完成状态也能成为结尾”。第二个候选在 seq21 得到 agency、causality、consequence、continuity、interest、pacing 全部 5，且 `blocking_issues=[]`。

S08 的 memory（B seq35）又明确要求“保留此前等待固化、使用替用凳子的结果”，并说“不补写未发生的试坐或承重验证”；seq38 两个 plan 仍都保持旧椅未验收，只在抹布、篮子和凳子摆放上作变化。实际效果是把“不能伪造已经发生的验证”扩大成“这一段也不能新发生验证”。这与改造方案允许世界发展、角色自主、当前选择产生后果的目标有冲突。

应让候选真正比较与当前目标相关的不同合法变化，评价过程检查主目标是否完成、延期是否有当前原因、结尾是否回应已建立的期待。不能只奖励没有硬冲突、没有替玩家承诺或场景足够安静。已有审核仍可通过却漏掉这种长期停滞，是这次真实样本揭示的限制。

### 3. 容量缩减后，原任务的可完成性没有进入这两次 memory 的事实正文

原 fixture 的 `chair-task` 包含工具、经验和通常一个下午能完成的前提。B/S07/seq11 的实际 memory 请求 `state.facts` 不含这条事实：`state_coverage.complete=false`，省略 8 条事实，`recent_from_revision=3`。B/S08/seq34 同样不含该事实，省略 13 条，窗口从 r4 开始。两次 `seed` 都只是“安静日常，第二人称。你是回老家休假的成年人许舟。”

`narrative.episodes` 仍保留 `chair-task` 的 ID 引用，但其摘要没有工具充足、基本经验或通常一下午这几个条件；较近的等待事实却完整可见。请求提供了 source_handle，原数据库也没有删除旧事实，因此这是输入选择与回取利用的问题，不是数据丢失。此轮模型没有回取该依据。

这能证实输入缺口，不能单凭一次轨迹量化它对最终正文的因果贡献；“历史未验证被永久化”的阶段目标同样直接可见。后续应检查活跃目标的条件和来源是否在裁剪后可用，必要时先回取再作完结判断，并用配对运行区分容量修复与提示修复的作用。

### 4. 慢写累积了重复说明，局部动作变化没有持续改变主关注点

S02 的木工步骤具有明确因果，S03 掉落豆角也由外婆自行处理，物件使用合理。S04 的“最近中午做得简单，炒个菜，热口饭。”（A/seq94/P2/[154,171)）确实是她自己的近况。不是所有细节都可互换，也不是每段都在说教。

但 S03–S06 长时间围绕一根老豆角的筋、归位工具、挪木胶和洗菜尚未完成展开。工具箱 S04 已归位，S06 正确承认“柜子下层的工具箱已经收妥，不必再动”（A/seq143/P1/[14,31)），这是好的连续性；同段又再次挪木胶，主修理目标没有新反馈。S05 玩家请求检查修理条件后，正文大段转到“您这把快择完了，要不要我帮着洗菜？”（A/seq120/P2/[114,131)），新的小家务承接自然，却占据了对原条件行动的回应位置。

近况沉默尤其被反复解释：S06 “她先前那句问话也还没有得到回答”（A/seq143/P3/[309,324)）；S07 “她没有再问刚才那句话”（B/seq32/P1/[116,126)）；S08 “没有重提你的近况”（B/seq52/P2/[188,196)）。人物的温和不催促已经通过具体行动成立，连续三页继续提示同一信息减少了留白，也把普通未答问题持续挂成任务状态。

修订时可以保留“工具已经归位”的正确记忆，同时减少无新作用的重复陈设与解释；让一个段落完成一项小变化，后续不再把它反复展开成未完事项。不能靠删除所有劳动细节或给外婆添加人生格言来提速。
