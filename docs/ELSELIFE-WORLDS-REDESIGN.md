# 世界与经历 · 2026-10-13

这是当前的产品页面设计方向。用户明确指出：一个故事就是一个不同的世界，产品的核心是进入世界并参与经历。此前以书架、书封和阅读管理组织入口的设计已取消。

## 当前实现

- 保留暖纸底色、灰紫强调与文学标题，桌面固定导航、手机底部导航。入口为“我的世界”“发现”“创造世界”。
- 我的世界以当前经历为中心，显示所选分支真实的地点、角色身份、时间和最近处境；返回入口进入原存档。其他经历以简洁列表切换，没有书封和作品数量。
- 探索页将最近经历压缩为返回入口，主要区域展示可进入的世界、公开设定和身份。抽象背景仅作氛围，不声称是生成的场景、世界地图或剧情事实。
- 世界详情突出身份、起始地点与进入世界；创造世界保持一个想法输入入口，详细编辑按需展开。
- 即时搜索保留中文输入法组合输入与焦点；经历管理保留置顶、备注、分组、封存、回收恢复与批量整理。菜单可外部点击或 Escape 关闭。
- 没有更改存档结构、现有故事正文、分支数据或模型生成规则。书店世界正文中的书籍词语是世界内容，原样保留。

## 研究依据

研究采用官方公开设计说明与产品流程。借鉴的是信息层级和任务组织，不是复制产品模板，也没有把登录后的完整产品体验作为已验证事实。

- [Linear 的界面重构](https://linear.app/now/how-we-redesigned-the-linear-ui)：固定导航、内容区域与操作层级，让常用任务有稳定位置。
- [Claude 的 Projects 改版](https://claude.com/resources/articles/projects-redesigned)：围绕持续任务组织上下文。这篇文章描述的是其特定项目体验，不能代表所有 Claude 界面。
- [Perplexity Spaces 官方流程](https://www.perplexity.ai/enterprise/videos/how-to-use-create-spaces)：侧边导航和集中任务空间。Elselife 将其落实为世界切换，不采用文档库语义。

## 验证

- 全量 Node 测试 495 项通过；日志 `test-results/worlds-full-tests.log`。
- 新增验证当前入口只使用当前分支的地点、角色与时间，旧置顶经历不会覆盖最新经历。
- 桌面用实际本地数据检查展示与搜索；浏览器错误日志为空。
- 隔离预览验证 320px 布局无横向溢出、返回已有世界与移动端探索；此前也检查了 390px、设置深浅主题、置顶恢复和筛选。
