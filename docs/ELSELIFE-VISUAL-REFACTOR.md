# elselife 视觉与交互重构依据

日期：2026-10-13。本文记录三份桌面参考资料的判断、重构前的问题与本轮选定方向，供后续实现和体验比较使用。

本轮把 elselife 组织成可以走入、接续和改写的阅读空间：故事内容成为主要视觉对象，操作清楚地贴近它；首页具有邀请感，阅读页保持长期使用所需的稳定。

## 三份参考资料各自提供什么

### frontend_aesthetic_judgment_prompt.md

核心是先判断表达是否成立，再打磨细节。形式应来自具体内容，构图、字体、颜色、操作共同组织注意力，不能用“高级”“克制”等标签代替判断。

对本项目的直接要求：真实开场和用户想法应进入首页构图；不能只把原有卡片换成紫色，也不能以更精细的阴影弥补没有主次的布局。应比较真实内容和连续使用中的差别。

### frontend_motion_master_prompt.md

核心是完整交互事件：触发被接住，变化有来源和去向，周围元素知道何时让位。动画应适应新的操作，支持进入、退出、反向、连续点击与减少动态模式。

对本项目的直接要求：选择开场时，选择器保持稳定，改变发生在对应内容区域；阅读正文不承担无关演出。生成、保存和失败反馈必须与真实状态一致，不能用预编排动画伪造进度。

### 落地页样板.html

样板是 Telos 的可交互产品展示页。其主要表现来自排版、CSS 纸页层级、SVG 连线和本地状态变化：文件没有图片标签、Canvas 或外部字体声明。

它包含九个叠加样式块。开头的鲜紫、较小字号和倾斜主卡并非最终呈现；最后的 `refinement-v9` 修正了这些选择。借鉴时须同时理解继承与最终覆盖关系。

真正成立的语言是编辑式版面与桌面纸页：不对称双栏、宋体展示字、无衬线操作、细横线、暖灰纸、灰紫强调、鼠尾草辅助色、正立主对象与偏置底纸。物感主要来自明度差和边缘，通常不需要纹理图片。

更重要的是对象身份持续：卡片展开为同一份阅读内容，关闭能回到来源；修改只触动相关字段，未变事实停留原处。它的价值不等于复制所有装饰或完整动画引擎。

## 重构前的具体问题

1. 产品页面和阅读页面分别声明绿色配色，基础样式又保留另一组视觉规则；层层覆盖增加了角色与控件不一致的可能。
2. 首页已有真实想法输入，但故事内容未形成足够鲜明的主对象。书架和表单容易成为同等权重的信息块，缺少一次清楚的注意力交接。
3. 书封以散列颜色、首字、圆环和拱形区分，能够提供秩序，但作品之间主要仍靠文字区分；几何装饰本身不应被误认为故事内容。
4. 部分元信息和操作使用 10–11px 字号，书封缩略文字更小。正文与操作需要分别检查可读性，不能以小字作为精致感的来源。
5. 通用悬停抬升、按钮按下位移与不同尺寸圆角并存。对于高频阅读操作，稳定的目标位置和清楚的状态差异更重要。

已有截图记录了历史版本，只能辅助理解演变；本轮比较必须使用实际运行的当前页面。

## 选定视觉方向与实现范围

首页左侧放置展示标题与真实想法表单，右侧呈现前三个真实预设故事的开场。使用原生 radio 切换，选择器和命中区保持稳定；开场取自现有数据，不编造效果演示或自动轮播。

全局采用暖灰纸、灰紫与鼠尾草的关系。宋体承担标题与阅读内容，无衬线承担操作与说明；细线、小圆角、有限的纸页偏置形成层级。书封延续现有作品入口的作用，以统一后的色彩和版式协调首页、书架与详情。

首页允许更大的字级与更鲜明的疏密；进入阅读后收回展示性元素，让连续正文、当前场景、页边工具和行动输入各有稳定位置。阅读业务 DOM 保持原有结构，避免视觉调整破坏生成、存档、分支、历史记录与辅助工具。

直接修订现有 `src/product-surfaces.css`、`src/reading-finish.css`，并在 `src/interface.css` 统一共同规则。共同颜色和控件规则应有明确归属，不再新增一个末尾覆盖层继续竞争。

## 取舍与后续判断依据

保留样板的内容主次、纸页层级、稳定操作目标和状态对应关系；不搬入八章营销长页、自动演示时间线、教学过程面板或完整几何展开引擎。

阅读正文不逐字播放，不因滚动反复显隐，不随指针漂移。交互表现优先投入开场切换、焦点、选中、展开与真实状态反馈，并服从键盘、触屏和减少动态偏好。

这轮取舍让首页承担作品气质，让阅读页承担长时间使用。若真实操作中纸页效果压过正文、短文案换行破坏控件或动态遮挡输入，应调整具体表达，不以样板外观为保留理由。
