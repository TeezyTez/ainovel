## 跨轮期待补测（最终规则）

serial 的三轮均成功，耗时78.4 / 73.9 / 50.6秒。第一轮建立 `present_relationship`（progressed）与 `private_recording`（open）；第二轮以相同ID、相同问题定义更新为 resolved；第三轮保留终态与第2轮原文证据，没有重复更新或强塞新谜团。

第一轮人物主动核对公开交接记录，没有偷播私人录音。第二轮获授权后完整播放，录音中“等手好了，我想把剩下半首和他吹完”与当下不立即恢复合作的选择形成区别。周岸以“刚才的道歉，不需要你拿合奏来换”回应，落实关系变化。该段第2轮结束；第3轮为明确标注的结束后压力测试，正常收尾，不能当作自然连载第3章。

这验证了期待跨轮建立与兑现的实际链路，没有验证长篇留存。三题材共12个接口样本回合（包括direct对照及结束后压力测试）均结构通过，另有1轮旧存档浏览器实际生成。最终补测完整记录包括每阶段的系统提示、输入、候选、选择与模型原始输出。构思阶段耗时约19–27秒，写作约31–51秒。

## 保证的范围

原句校验能证明证据文字存在，不能证明它逻辑上足以支持事件或解谜结论。期待记录有界，淘汰的终态 ID 不保留永久墓碑，也不能识别换名重开的同一问题。知识边界、文笔、创意与长期读者兴趣仍需实际阅读评估。本次没有宣称无限记忆、完整人物心理仿真或“上瘾公式”。
