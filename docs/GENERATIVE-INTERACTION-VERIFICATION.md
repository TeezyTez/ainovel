# 智能交互验证记录 · 2026-10-13

本次沿用动态交互的公开上下文、服务器审核、账本和规则执行流程，新增六种可组合视图。后续依据用户要求调整为按需自动出现：移除手动启动与格式选择器，进入场景或每轮剧情更新后由模型判断必要性和呈现形式。协议版本为 `elselife-dynamic-5`，旧缓存会自动重新判断。

## 已实现

- 表格：表达式数据、最多8列50行、数值／文本排序、关键词筛选。
- SVG 关系／流程图：已知节点、方向连线、来源或不确定性标签，以及完整文字说明。
- SVG 条形图：真实零基线、正负数、公开数据列表，不把未知量当作0。
- 卡片与时间线：区分来源、待核事项与行动方向；提示可追加到现有草稿。
- SVG 概念插画：受限图元和颜色，标示为概念示意，提供文字描述。
- 可与现有输入、多步骤准备、条件显示、预览和正式动作组合。
- 自动选择和显式请求复用同一条生成／审核流程。生成不提交回合，玩家不需要启动功能或选择表格／图示格式。每个回合只自动判断一次，普通阅读返回无需界面。
- 取消或跨分支迟到响应不安装；切换后恢复新分支自动准备；同一协议版本的有效旧视图在生成失败时保留。旧版本面板先隐藏再重新判断，不会因生成失败而伪装成新版结果。单个组件的数据缺失不隐藏同组其他组件。

## 边界

这是一组可组合的数据组件，不运行模型编写的任意网页或脚本。模型选择、内容真实性与语义审核仍有局限；缺少依据时应显示未知。生成需要真实模型，预设演示保留已有本地资料查看。仍采用完整JSON响应，不支持逐字流式生成。窄屏使用桌面浏览器尺寸模拟，未进行实体手机或屏幕阅读器实机测试。
