# 光学世界入口 · 2026-10-13

用户认可“世界与经历”的结构，希望进一步增加未来感、材质和原创动效。本轮保留既有世界导航与暖纸灰紫底色，将主要视觉表达集中在进入世界这一动作。

## 研究与设计判断

- [Spline 官方产品页](https://spline.design/)介绍分层材质、实时交互、状态与事件，以及玻璃、噪声、空间投影。本项目采用本地绘制的光学入口和指针响应，没有嵌入外部 Spline 场景。
- [ElevenLabs 官方品牌规范](https://elevenlabs.io/brand)将数字渐变与触感纹理结合，并使用程序图形表达产品特征。这里采用细密光学纹理和珠光材质，图形来自世界 ID，未使用其品牌素材。
- [Runway 官方页面](https://runway.com/)强调模拟不同世界和经历。本项目将这种空间语义用于入口连续性，而非搬用影视宣传内容。
- 也检索了 Anthropic 和 Luma 的公开入口。Luma 内容读取及外部交互页浏览受工具限制，未作为已观察到的实时动效证据。上述研究基于官方公开说明，不声称已完整实测这些产品。

## 实现

- 世界入口使用 Canvas 2D 绘制带纵深的环面与不同轮廓。世界 ID 决定形态与配色；图形不是剧情地图、场景事实或模型生成状态。
- 指针驱动视角和光场，指数阻尼收敛；离开后归位。初次出现约 1.1 秒后结束动态，交互停止后不保留常驻渲染循环。
- 探索到详情使用实际画布快照，按光学形态的中心及尺度移动。只有装饰形态参与转场，目标画布在完成、中断或异常时恢复。导航和内容立即可用。
- 背景、侧栏、品牌标识、按钮与创作输入区增加珠光、细噪声、轻微浮起和聚焦反馈。正文不增加持续运动。
- 离屏不更新；隐藏标签页停止调度；画布像素倍率上限为 1.5。系统或应用减少动态设置保留静态图形并取消动态。不请求外部图像，不增加依赖或模型调用。

## 验证

- `npm test`：501 项通过，0 失败，日志 `test-results/portal-full-tests.log`。
- 新增测试覆盖曲面闭合、有限坐标、入场与指针归位后停止调度、离屏暂停、重建清理、销毁、两类减少动态偏好，以及不同构图下的转场坐标对齐。
- 浏览器实测鼠标拖动经过入口时光场变化、进入详情时浮层出现、结束后浮层清除且目标画布恢复；没有浏览器错误日志。
- 隔离环境验证 390px 和 320px 无横向溢出，深色主题与减少动态可用；随后恢复隔离预览偏好。实际用户的故事、存档、草稿与设置未作数据修改。
