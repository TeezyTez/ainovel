# 动态艺术虫洞：首页实施记录

用户在预览后明确修正：仅需要有艺术感、设计感的动态虫洞，不把世界图片、名称或入口放进虫洞。随后要求扩大覆盖范围、无人操作时仍持续缓慢吸入，并增加鼠标本身的特效。以下是当前最终范围，取代研究笔记中的交互入口建议。

最新澄清：扩大的应是周围被吸入的动效范围，不是虫洞主体。主体缩回放大前的视觉尺度；独立的 24 条弧形光丝从画布外围分批向洞心收拢。14 秒周期包含三批错开的吸入和安静间隔，洞心投影随主体姿态实时更新，自动播放、暂停、减少动画和销毁逻辑共用原控制器。桌面浅色/深色采样及浏览器检查已验证。

多元感细化：主光丝分为冰蓝、紫、香槟三组，不同色温对应不同曲率和吸入速度；六条主轨迹带成对的淡色平行回声，在中段分离、靠近洞心时合拢。主体曲面增加三道缓慢错位的虹彩褶皱与细微内缘光，保持原大小与原来的自动吸入节奏。共 36 条带状轨迹，仍为同一个 draw call；不增加交互入口或额外文字。桌面明暗主题、手机和完整自动播放/暂停/导航/减少动画/回退浏览器检查已通过。

后续精修：深色内部光点减少、调暗，并向洞心渐隐。光点改用固定随机种子的稀疏分布，间距、大小、强弱及呼吸相位各异，整体仍沿曲面缓慢向内流；邻格采样与圆周种子包裹保证动画连续。用户指出三道褶皱像扇叶，因此取消三重对称窄光带，替换为低强度、不对称的宽幅光泽。

材质与节奏打磨：细化经纬线的强弱关系，按曲面法线提供掠射明暗，喉部网格向深处渐隐，洞心使用暗色径向渐变；外围光丝按首屏可见边界柔和淡出，周期放缓至 20 秒并保留静默间隔。用户明确要求保留颜色，最终恢复蓝紫、青色、暖金虹彩，不能将“高级感”等同于灰化。随机光点的保留概率由 70% 降至 42%，主体大小及大范围自动吸入继续保留。明暗采样、主题切换、移动端、暂停/减少动画、导航及回退浏览器验证通过。

## 实施顺序

1. 首页主视觉为单个纯装饰参数曲面，不读取世界或存档数据。标题和创建按钮保留普通网页布局，世界选择继续由下方目录承担。
2. 固定 Three.js 依赖，通过精确白名单提供两个运行时模块；不开放 node_modules 目录。先补 HTTP 白名单测试。
3. 单 Canvas 呈现广域曲面、虹彩网格、空洞与光丝；持续时间驱动环线和光丝向洞心流动。鼠标仅叠加有限偏转、局部形变，以及非阻挡的光晕与六点短尾迹。没有自动跳转、世界图像、入口标签或滚动锁定。
4. 控制器负责异步挂载竞争、卸载、资源回收、离屏/后台暂停、系统与应用减少动态偏好、初始化失败静态回退。标题及操作始终保留 DOM。
5. 全量 Node 测试与真实浏览器验证：桌面/窄屏、不移动鼠标时画面仍变化、光晕、暂停、目录导航、减少动态、失败回退、反复进出首页。

## 验证重点

- 空世界仍可显示装饰；虫洞不接受世界数据，筛选与隐藏仅影响正常目录。
- 用户在异步加载完成前离开首页；旧实例不能复活。
- 返回首页后不能累积画布、监听器或 WebGL 上下文。
- 手机目录可点击；首屏文字保持可读；无横向溢出；触摸不保留鼠标光晕。
- 默认轻量渲染，画布像素比上限 1.5；无法创建 WebGL 时仍能选世界。
