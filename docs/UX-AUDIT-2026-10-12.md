# 方糖产品体验核验与修复

日期：2026-10-12

本轮沿实际流程核查发现页、开局详情、创建世界、书架、阅读、地图与资料、历史回顾、分支存档、阅读设置、全局设置及导入导出入口。交付是当前仓库的代码修改；并非一份待实施规划，也不据此宣称产品已达到完整商业化标准。

## 已修复的问题

| 环节 | 原问题及影响 | 本轮处理 |
| --- | --- | --- |
| 页面跳转 | 全局平滑滚动让新页面从旧位置滑过，返回列表丢失浏览位置 | 切页即时定位；记录页面滚动位置；阅读保留段落锚点 |
| 设置导航 | 分类使用无效路由形式的锚点，复制或特殊打开容易进入错误页面 | 改成页内按钮，定位对应区域并移动键盘焦点 |
| 面板返回 | 地图进详情、故事选项进设置后缺少一致的返回路径 | 共用返回栈，保留真实 DOM 节点、表单值、事件监听和滚动位置 |
| 异步面板 | 新增返回栈可能退回已经结束的等待画面 | 结果与失败替换等待画面；等待中返回会取消任务，旧响应不能重新打开面板 |
| 焦点 | 关闭面板可能抢走原文跳转或草稿的焦点；嵌套命名表单未自动聚焦 | 区分关闭回焦与主动跳转；命名输入框显式聚焦，信息面板聚焦标题 |
| 开局详情 | 继续旧存档和新建存档主次不清，容易重复开始 | 已有存档时主按钮为继续阅读，新开局放入“重新开始” |
| 创建世界 | “保存并开始”实际进入预览，承诺与结果不一致 | 改为“保存并预览”；低频资料导入保持折叠；移除重复填写入口 |
| 创建失败 | 本机保存失败仍可能离开表单、清除草稿 | 世界与故事创建先确认保存成功；失败保留原表单与草稿 |
| 一句话开局 | 无法保存请求仍可能发起生成，失败主要靠短暂提示 | 保存失败时不发起请求；生成错误留在页面，保留原想法 |
| 草稿保存 | 跳转清除了防抖计时器，部分路径没有补写 | 跳转时补写当前数据；页面保留可处理的保存失败提示 |
| 对象起草 | 从人物资料起草行动会覆盖已输入文字 | 追加到已有草稿，附上来源引用，不自动发送 |
| 表达复用 | 尚未复用也可“恢复草稿”，且复用后面板挡住输入框 | 恢复入口按故事和分支启用；复用后关闭面板并聚焦输入 |
| 保存错误 | 容量或浏览器存储错误也打开“另一标签页冲突” | 区分普通保存失败和实际版本冲突；保留导出与重试入口 |
| 暂停 | “今天先到这里”默认选项会封存故事 | 默认暂停；结束并封存需要明确选择 |
| 存档入口 | 分支面板提示“保存此刻”，按钮却藏在别的菜单里 | 在分支与存档面板直接提供保存节点入口 |
| 阅读设置 | “恢复默认”立即保存，关闭面板无法取消 | 只修改表单，点击应用后才持久化 |
| 设置一致性 | 两处字号、行距、宽度范围不同；存在无实际作用的开关 | 统一范围，移除无效建议开关和专注按钮；叙述偏好集中到阅读设置 |
| 全局设置 | 普通偏好、服务端配置、备份细节与开发日志混在长页面中 | 阅读、叙述偏好、模型、数据分区；配置、备份和开发信息按需展开 |
| 模型状态刷新 | 配置请求返回时重绘首页，可能打断输入焦点 | 只更新可用状态和按钮，不替换正在填写的表单 |
| 筛选 | 修改分类后还需要额外点击查找；重置未清除排除标签 | 下拉框与勾选即时应用；完整清空条件，并恢复筛选控件焦点 |
| 阅读干扰 | 重复回合标题、版本号、长说明、单字对象链接干扰阅读 | 精简重复元信息；用户输入可折叠查看；单字通用词不再自动变成链接 |
| 历史资料 | 搜索与快照页面反复解释系统规则，范围字段常驻 | 保留历史及证据性质提示，精简解释；范围与私人笔记折叠 |
| 历史上下文 | 关闭历史面板后可能继续沿用它的查询快照 | 面板关闭及切换分支时清理查询上下文；面板返回时恢复相应快照 |
| 地图 | 已展开地图仍有“展开”按钮；没有连线也展示宽画布与滚动条 | 隐藏重复展开入口；未记录连接时使用响应式地点布局，不虚构路线 |
| 输入区遮挡 | 固定输入区变高后，正文末尾可能被覆盖 | 正文留白和“新内容”按钮随输入区实际高度变化 |
| 小屏布局 | 长摘要占满故事卡；资料面板层级和按钮间距不统一 | 摘要限制三行；统一面板布局，验证 390 × 844 视口下的工具与设置 |
| 导出含义 | “完整存档”容易让人误以为单个文件可以完整迁移 | 改称“本机记录”，在备份说明中明确服务端数据与浏览器身份的依赖 |
| 下载时序 | 旧弹窗延迟关闭事件可能提前释放新导出文件 URL | 只在弹窗实际关闭后释放下载资源 |
| 演示清理 | 清理演示是永久移除，恢复困难 | 改为移入回收箱，可恢复 |

没有改写现有故事正文、事件或世界事实。支付、社区和云同步未加入本轮范围。

## 验收证据

- `node --test tests/*.test.mjs`：281 项通过，0 失败、0 跳过。
- 9 个相关 JavaScript 文件通过 `node --check`；`git diff --check` 通过。
- 新增 5 项回归检查：恢复默认未应用不保存、对象起草不覆盖输入、继续存档优先、单字不误链接、设置路由及备份说明。

- 独立只读审查发现了异步面板历史问题和输入区遮挡风险。两项均已修复；面板替换经审查者的内存 DOM 最小复现再次验证。

### 浏览器实际操作

在 `localhost:4173` 新建独立演示存档及“体验核验 · 灯塔”手动世界；没有推进或重写用户 `127.0.0.1:4173` 下的现有故事。

| 操作 | 结果 |
| --- | --- |
| 发现页选择标签、清空筛选、进入详情并返回 | 结果即时变化；恢复列表浏览位置 |
| 设置分类按钮 | 定位对应区域，URL 保持设置路由 |
| 现有世界继续入口、新开一局、选择演示 | 旧存档为主入口；独立新存档创建成功 |

## 尚未解决或未验证的范围

1. **完整备份与跨设备续玩仍不成熟。** 浏览器导出不包含新开局全部服务端设定与身份，现已准确标注；尚未实现一个可迁移的完整备份包或云同步。
2. **生成质量与延迟没有在本轮重新做真实模型评测。** 浏览器续读使用明确标记的演示，不能据此声称真实剧情质量已改善。
3. **手机验证是浏览器视口测试。** 未在实体 iOS/Android 设备上验证软键盘、安全区域和浏览器差异，也未做完整屏幕阅读器审计。
4. **存储配额和多标签冲突的异常路径主要由既有自动化测试及代码审查覆盖。** 本轮没有在用户实际浏览器中人为填满存储容量或制造冲突。
5. **前端仍有历史债务。** `app.js` 保留较多流程处理，样式也含早期叠加规则；本轮抽出设置视图和对话框导航，但未进行无边界的技术重写。

这些限制与已通过的 UI 验收分开记录，避免把界面改善等同于完整生产就绪。
