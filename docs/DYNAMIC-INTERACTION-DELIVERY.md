# ElseLife 动态智能界面：实施与验收记录

日期：2026-10-12。需求依据为完整阅读的《ElseLife｜动态智能界面开发任务书》。实施前检查了 README、实现文档、动态玩法审查、权威账本说明、现有接口与源代码；项目及已检查的父目录未发现 AGENTS.md。沿用原生 ES modules、CSS、Node HTTP 和现有模型传输，没有引入其他产品的业务架构或新框架。

## 实际实现

原先的 game 模块能保存实体和固定效果，但不能表达参数化多步行为，也需要正文生成成功后才提交行动。本次增加的能力如下。

| 部分 | 实际代码与行为 |
| --- | --- |
| 通用规则 | `src/dynamic-rules.js`：数据表达式、嵌套/重复/条件显示、局部字段、单选/多选、跨字段校验、条件步骤、精确有限小数计算、资源与状态效果。没有按场景名分派页面。 |
| 模型契约 | `src/server-dynamic-model.mjs`：版本化的准备、世界一致性审核、自由输入解释、回执续写、续写审核提示。模型可明确返回 null。故事文本不能扩大工具权限。 |
| 权威执行 | `src/server-dynamic.mjs`：从服务端状态生成归属、审核并登记契约；检查 scope、digest、对象、参数、条件和版本；一次保存完整效果与回执；之后才生成正文。 |
| 存档与恢复 | `src/core.js`、`src/server-branch-ledger.mjs`：操作作为已完成回合保存，回执可确定重放。叙事状态单独保存；重复请求、恢复和叙事重试不重复扣除资源。 |
| 玩家视角 | `src/server-public-archive.mjs`：动态编排始终使用玩家投影，包括旧作者档案。未公开人物、私有字段、flag、隐藏事件和原始世界规则不进入动态界面上下文。完整世界仍保留在服务器供世界审核使用。 |
| 阅读界面 | `src/dynamic-ui.js` / `.css`、阅读页及 app：正文附近按需出现一个辅助交互，纯查看不推进故事；多步草稿保存，历史交互只读；功能入口在「+ → 整理当前处境」。回看历史页时收起当前行动。 |
| 自由行动 | 已审核规则独立于当前显示布局保存。只读比较没有购买按钮时，玩家仍可自由购买；需要时先基于当前事实生成并审核新契约。旧契约只作理解依据，过期后不能执行。超出确定规则的交涉保留结构化申请，进入原有世界叙事裁定。 |

按钮提交结构化的世界/故事/分支/场景/来源片段/数据版本、契约 ID 与修订、SHA256 摘要、动作 ID、对象列表、参数和请求 ID。客户端不提交权威状态，不自行决定成功。导入的契约必须在当前服务器重新审核，不能靠客户端伪造审核标记。

编排上下文包括当前位置、时间、公开事实、已知人物、近期原文、当前意图、未完成交互及设备/阅读状态。设备变化以 CSS 适配，不因此重复抽取报价。自动出现的内容不主动聚焦，读取和结果合并保留正在编辑的文字。

## 数据与接口

继续兼容现有 `schemaVersion: 1` 档案，通过可选字段扩展，而非重写全部旧存档：

- `branch.dynamic`：当前提议、归属、摘要、提示版本，以及明确的 null 决策或失败说明。
- `turn.operation`：冻结的定义、结构化请求、正式回执。回执包含前后版本、每个对象的前后值和公开结果。
- `turn.narration`：pending / complete / failed 与修订号。正文失败保留正式回执；重试只续写。
- `turn.actionIntent`：需要人物判断的结构化行动申请，不代表申请已经获准。
- `dynamicDraft` / `dynamicDraftHistory`：本地多步输入、阶段和展开状态；合并服务端进展时保留，随 JSON 备份导出。
- `interactionSnapshot` / `openingInteraction`：历史交互说明，不再提供有效提交入口。

服务器另存审核记录、同版本规则目录、幂等回执和最多 500 条动态诊断事件；这些不是浏览器可自行授予的权限。

| 接口 | 用途 |
| --- | --- |
| POST `/api/interaction/prepare` | 从权威分支编排、校验、审核并保存交互；相同事实与意图复用。显式 retry 可以重新整理。 |
| POST `/api/interaction/execute` | 无模型参与的确定规则结算。全部效果通过后一起落盘。 |
| POST `/api/interaction/narrate` | 仅为已提交操作补写正文；再次请求已完成操作不重新生成或结算。 |
| POST `/api/generate` | 自由输入先解释；匹配确定规则时进入同一执行器，必要时编排新契约；人物判断仍走原有叙事流程。 |
| POST `/api/branch/read` | 恢复当前权威分支，也返回动态操作的已提交回执。 |

沿用 `x-branch-owner`、本机来源检查、单进程分支锁和文件原子保存。收到成功响应前数据已保存；回复丢失仍可恢复。不同内容复用相同请求 ID、错对象、过期报价、跨分支与错误摘要均被拒绝。

## 真实模型验收

使用已有本机 Codex 登录和 `gpt-6-astra`，没有以演示提供器替代模型。首次在受限环境运行时，Codex 自身状态目录只读导致失败；随后在获准的本机执行环境下运行，未复制令牌或把密钥传给浏览器。

```powershell
# 不调用模型，仅核对测试内容
node scripts/verify-dynamic-interactions.mjs

# 完整真实模型验证，使用隔离临时账本
node scripts/verify-dynamic-interactions.mjs --live

# 可单独复测；名称仅存在于验收脚本
node scripts/verify-dynamic-interactions.mjs --live --case=packing,ballot

# 基于已有实测产物，验证不同意图及人物交涉
node scripts/verify-dynamic-continuity.mjs --live --source=test-results/dynamic-live-2026-10-12T08-03-51.775Z
```

世界内容与正式初始状态由测试提供，界面、参数、规则、意图解释和正文由真实模型生成。测试脚本是验收输入，不被产品代码导入，也没有在产品中增加对应场景分支。

| 情境 | 验证到的不同语义 |
| --- | --- |
| 商人交易 | 数量与总价、钱/库存/持有量同时结算；药效保留为商人声称。2 瓶后的数量为 4 / 3 / 2。 |
| 航报比较 | 比较不同时间、来源与可信程度；不擅自选择路线。 |
| 公共水分配 | 两个目的地与共同预算：12 → 1，分得 5 与 6；两步准备。 |
| 实验校准 | 先选温度，再填批次，核对执行；低温 3 批消耗 6，产出 3；三步。 |
| 撤离装载 | 多选组合、总重量条件、只改变选中物品的装载状态。 |
| 私信查阅 | 收集目的与保密安排，动作标为“尝试”；不能用公式保证馆员同意。 |
| 设备预约 | 设备与时段的条件选择；只修改所选空档。 |
| 临时制作 | **模型生成四步规则组合**：支撑、跨度、加布资格、核对扣料；实际执行双层 2 米加布，保存并重放。 |
| 个人投票 | 比较理由与未知成本，只记录个人一票，不宣告集体通过。 |
| 事故线索 | 时间与来源对照；不将矛盾自动解释为说谎，不凭空“破案”。 |
| 干粮转交 | 同时检查交付范围和自己保留的下限，双方余量原子变化。 |
| 听雨读书 | 明确 null，只有正文。 |
| 商人闲聊 | 没有报价与购买意图，不因“商人”身份生成交易入口。 |
| 长椅看晚霞 | 明确 null，不强迫玩家点选。 |

数量为商人 + 10 个其他情境 + 3 个无需界面的情境。四步制作成功证据在 `test-results/dynamic-live-2026-10-12T08-15-42.911Z/assembly/`，包含模型输入输出、执行结果、正文和可恢复档案。

**这些结果不是某一次整批 14/14 的首次成功率。** 开发期间三个完整批次分别是 10/14、12/14、12/14。发现并修正了条件字段上下文、连续数值被误限为整数、数组/求和表达和审核器缺少宿主自由输入说明等通用问题。部分无效生成被拒绝并降级，针对性复测后 14 个情境均有成功实测产物，最终代码重放全部通过。每轮代码指纹及所有失败保留在证据索引中；没有为某个故事添加产品页面或关键词处理器。

额外连续性实测 `test-results/dynamic-continuity-1791793703442/report.json` 为通过：

1. 同一商人事实下，“只比较”生成无购买动作的只读界面，数量不变。
2. 随后自由输入“买 2 瓶”，先形成审核过的行动契约，再正式结算为 4 / 3 / 2。
3. 馆员交涉实际进入现有真实叙事生成链，提供有限线索并提出后续条件，没有自动同意开放整封信，也没有将尝试伪装为确定结算。

基础情境证据保存了 149 条调用记录（包括一次受限环境启动失败）；成功返回调用的中位耗时约 17 秒、最长约 65 秒。一次完整交互可能有多次调用，因此这不是整条链路延迟。附加连续性与浏览器调用未计入该组统计。当前传输没有暴露可靠 token 用量，记录为 null，不估算成本。

## 尚未覆盖与运行边界

- 规则语言是有界的数据解释器，不运行任意生成代码。当前直接效果是已登记对象的数值增减与公开状态变化；不支持任意工具、网络、数据库写入和无限规则。超出表达能力的行为保留原输入进入叙事尝试，不伪称确定成功。
- 确定数值支持至多 12 位有限小数和绝对值 10¹²，并拒绝无法在现有数值存档中精确表示的结果。无限循环小数、无穷计算和超限定义不执行。没有新增随机规则指令；需要随机或人物自主判断的结果仍通过既有叙事提交保存。
- 格式、引用、权限、版本、计算与重放可确定检查；模型生成的世界规则语义由单独审核辅助，并非形式化证明。真实模型仍可能拒绝合理提议或产生不合格结果；文本层面的长期一致性与认知边界仍需持续评估。
- 不支持多服务进程共写同一文件账本、云账号迁移或突然断电下的所有硬件故障。浏览器清理数据或丢失所有者标识也不是自动云恢复；受保护故事需完整服务端备份。
- 模型响应仍为完整 JSON，非流式。长故事超过上下文或对象上限会明确失败；没有宣称覆盖任意规模、任意新玩法。
- 窄屏和键盘以桌面浏览器验证；实体手机软键盘、中文输入法的设备级组合输入和屏幕阅读器尚未进行实机验收。
- 未改生产服务、未部署、未提交或覆盖其他未提交改动。交付是当前工作区代码、本机预览和可复现证据。
