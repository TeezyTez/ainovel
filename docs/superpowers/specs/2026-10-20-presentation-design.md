# ElseLife 页边记事呈现设计

本轮在现有 Flutter 阅读器中建立正文、公开资料与回读位置之间的联系。附件授权在任务范围内直接选择、实现和验证可回退方案；不等待额外设计审批，不发布到外部。保留当前工作树已有的叙事、分支和恢复改动。

## 观察与范围

- `experience_screen.dart` 的桌面资料栏遍历最新 `view.information`；页眉使用最后一页。实际浏览器确认，长事实的标题和摘要重复，人物初始记录被挤到下方。代码确认分页回读旧页时仍显示最新资料。
- `reader_tools.dart` 的正文提及已经读取各页 `page.reader.information`；`reader_position.dart` 已支持源文字锚点。沿用这两个边界。
- 提交针对正式最新 revision，回读不会改变行动基准。这是原有产品规则。
- Go 的 `recorded_revision` 是事实建档版本，不是获知时间；每页 `reader` 是该页公开快照。新公开不等于新发生。

本轮只改前端呈现、阅读定位衔接与相关测试。无接口、数据库、生成规则、模型调用频率或外部依赖变化。

## 候选与比较

以同一组公开快照比较三种组织方式：

1. **随页累计资料**：将现有资料栏改为该页完整资料。能纠正时间错位，但累积后仍不能区分本页带来的记载。
2. **页边记事**：正文后短入口；在阅读页旁显示本页新记和更新，按需展开此前同一记录或明确关联的旧记；完整截至该页资料仍可访问。选择此项。
3. **独立变化时间轴**：所有页差异另排成长流。增加一条竞争正文的阅读线，稀疏故事也需要在两套时间轴间跳转，本轮不采用。

比较使用相同的正文和数据，不更换材料为某方案争取优势。窄屏通过同一面板检查，而非压缩桌面侧栏。最终保留案例不参与初始参数调优。比较原型和实测记录置于忽略目录 `.validation/presentation-20261020/`；正式交付记录在 `notes/`。

## 呈现与行为

- 保留正文排版选择和连续／分页两种阅读。每页结尾增加短入口，提示本页记载数量，不在正文中重复整套资料。
- 桌面复用已有侧栏为“页边记事”；窄屏与专注阅读由工具栏和页尾打开同一面板。沿用侧栏的理由是便于将前文记载与原文并读，不是把常驻性等同于侧栏。
- 面板明确“第 N 页”，默认展示该页相对前一页新增或更新的公开资料。另一视图展示截至该页的完整资料。长事实不重复作为长标题与摘要。
- 记录保留人物说法、人物相信、初次记载等类型差别。更新记录可读前后原文；关联仅使用服务端明确的 `relatedIds`，不推断关系变化或因果。
- 首次公开位置从相同 ID 和内容的公开页快照获得，标签是该页的记载，不声称它必然是原文证据。不得从 `recorded_revision` 推断来源。历史快照缺失则显示不可比较，禁止回填最新资料。
- 连续模式从视口正文锚点确定阅读页，分页从当前页确定。回读时在行动区域提示“回读第 N 页，行动接续第 M 页”，提供回到最新；保留草稿与行动版本校验。
- 从记事回到较早页前保存返回锚点，回读后能返回原文字位置。分支变化清除返回目标；失败或取消不产生虚假新记。
- 复用现有字号、主题、减少动效与阅读位置存储。不为显示差异请求模型，不新增世界事实。

## 验证与完成

- 单元测试：迟公开的旧事实、缺快照、同 ID 更新、关联过滤、无变化、分支、排序不应制造变化。
- Widget 测试：旧页不显示后页记录，滚动同步、页尾入口、来源与返回、草稿不变、200% 字体和窄视口。
- 真实产品：新建专属“呈现验证”故事；浏览器输入一次行动，观察生成状态、正式结果、资料变化，回看并返回／刷新。不触碰已有用户故事。
- 对比材料：日常场景与封存基准的不同节奏场景；零值／未知／不适用作为保留反例。明确区分合成夹具、封存回放和新真实模型调用。
- 完成 Flutter 定向／全量测试、分析、Web 构建及项目协议检查；记录运行命令、截图、已观察结果和未覆盖设备条件。

设计判断不是用户研究结论。无真实目标读者研究时，不声称提高了理解、喜爱或沉浸程度。
