# 对话中的智能交互

目标：让模型按剧情与读者请求选择合适的表达与操作方式，提升理解和参与的多样性。沿用现有自动 prepare → 校验 → 审核 → 保存流程，不增加平行状态系统或生产依赖。

- 扩展现有数据协议：比较表、SVG 关系／流程图、数值图、卡片、时间线、声明式 SVG 插画。只读视图可与已有条件输入、多选、多步骤和正式动作组合。
- 每个当前场景由 prepare 自动判断是否需要辅助呈现，自行选择格式；用户无需打开入口或选择展示方式。普通行动和人物对话仍经过故事流程；生成界面不推进回合。
- 表格筛选／排序只影响显示；图卡提示只追加草稿。保留用户在请求期间输入的文字，拒绝过期异步结果，离开时取消生成。
- 使用受控 SVG 元素和文本转义。插画标示为概念示意；事实、传闻和推测由模型及现有审核区分，不制造数值或关系。
- 验证协议边界、渲染、输入路由、取消与草稿；运行完整 Node 测试、隔离真实模型试验和桌面／窄屏浏览器检查。

分工：协议及模型提示、渲染及样式、对话及控件集成并行；真实模型脚本使用隔离账本。基线测试 376/376。
