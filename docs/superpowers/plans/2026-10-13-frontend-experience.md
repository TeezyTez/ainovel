# 前端体验优化 · 2026-10-13

用户在当前页面审查后授权全面优化。沿用现有本地项目和存档协议，在当前未提交工作之上修改；变更前副本保存于 `test-results/frontend-design-before-20261013/`。不发布、不改写用户的故事正文。

## 设计约束

- 让发现、开始、阅读、返回形成连续旅程。高频动作可见，低频选项收起，所有异步操作给出真实反馈。
- 保留暖纸、宋体与灰紫的品牌语气；世界内容而非重复装饰决定视觉主次。文字至少达到实际可读的尺寸，图标与触控区域分开设计。
- 真实生成、预设演示和只读开场呈现各自真正可用的操作。
- 新界面不迁移或更改已保存的剧情事实；资料名称只做展示摘要，完整原文可查。
- 不引入框架或生产依赖，不另外增加全站末尾样式覆盖文件。

## 实施分工

1. 阅读：在输入框旁显示继续按钮，演示建议只写入草稿；只读开场显示连接入口；等待/结束状态禁用相应动作。整理阅读工具的触达、标题与移动布局。拥有 reading-ui.js、reading-finish.css 和对应测试。
2. 世界库：首页加入有剧情摘要的继续入口；发现卡片呈现题材、身份和短开场；存档始终显示剧情摘要、回合/分支上下文，避免同名存档混淆。拥有 library-ui.js、product-shell.js 和对应测试。
3. 状态与性能：节流阅读锚点保存并去掉整分支复制；修复模型可用状态更新、导航焦点；资料的长名称保留来源并缩短显示。拥有 app.js、experience-controls.js、personal-library.js、spatial-map-view.js 和对应测试，与阅读代理协调接口。
4. 主代理：统一 product-surfaces.css、world-materials.css、interface.css 的可读性和色彩，改善创作与详情流程（experience-views.js）。保留世界氛围但减弱重复环形主导；用排版、留白和内容形成变化。

- 最后独立审查新增变更，修复重要回归并记录实际验证与限制。
