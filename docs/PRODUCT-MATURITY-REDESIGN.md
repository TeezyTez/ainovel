# 阅读产品重构 · 2026-10-13

## 真实体验问题

审查了当前灰港故事的五次续写及页面状态。问题集中在：发现页相似矩形堆叠，故事缺少辨识度；正文被回合框架割碎；约十九个工具混在一个菜单；发送和下一条草稿混在一起；失败只能输入口令恢复；辅助内容是临时结果，历史只留标题；生成有重复复述和后台信息突然出现的情况。

## 视觉与控件

- 纸白、石墨、森林绿；深色主题保持对应层级。正文服从已有字号、字距、行距与字体偏好。
- 发现页采用抽象几何与中文排版书封，封面仅用于辨识作品，不冒充剧情中已发生的场景，也不请求第三方图片。
- 按钮有主行动、普通行动和图标操作三层；表单提供稳定标签、焦点与错误状态。
- 书架分类显式显示计数，搜索与整理各有位置。创作是编辑任务，不再把所有字段等权展开。
- 自动辅助仍由上下文决定，普通阅读安静退出；没有格式选择器。辅助表格强调差异，共通未知只说明一次。

## 交互与数据边界

- 生成请求协商 NDJSON，阶段为 preparing / writing / checking / saving；这些事件来自实际执行位置，不使用假的百分比。结果只有提交确认后才发送。
- 已提交输入与下一条草稿分离。原请求先记入请求日志，失败或断线按同一请求 ID 恢复，避免重复行动；收到结果不清掉生成期间输入的新草稿。
- 历史资料只使用相应回合公开快照复原。排序、筛选、查看图示不触发故事行动。
- 叙事保持原有两阶段链，未增加额外模型审稿。关注直接回答、行动有结果、避免重复收尾、新资料有读者可接触的来源。

## 验证证据

测试数据与真实用户存档分开；固定数据浏览器验收用于交互和布局，独立真实模型案例用于叙事与记录质量，二者不能互相代替。

- `git diff --check` 和修改入口的 Node 语法检查通过。首页、新样式、历史快照模块均返回 HTTP 200。
- 新增覆盖：真实 HTTP 生成阶段与提交时序、同请求幂等、中文分块、断流及校验失败不提交；开场/历史快照边界；资料检索、弹窗层级；跨故事失败恢复、离线恢复、下一条草稿保留。

- 独立 4174 测试服务：生成期间继续写下一条草稿，成功、失败和重试后草稿均保留；重试只产生一次有效回合。
- 历史表格可排序，图示可放大，历史行动不能再次执行；桌面资料侧栏打开时可编辑正文输入框，上层图示按 Escape 关闭后侧栏仍在。

- 真实 4173 页面：原有 5 回合及“继续”草稿仍在；资料概览将长列表缩为摘要，完整 14 条线索仍可打开，没有控制台错误。没有用验收行动续写用户存档。
- 本地服务已重启至新代码。实景截图：`test-results/product-home-final.jpg`、`test-results/product-reader-final.jpg`。

### 真实模型与限制

- 独立三组真实模型复测均首次通过记录校验，分别约 25.1 / 36.2 / 39.3 秒，两次模型调用完成；来源文件在测试期间没有变化。详见 [叙事质量复测](NARRATIVE-QUALITY-2026-10-13.md)。
- 本次没有增加第三次模型审稿，也没有把阶段提示冒充正文流式输出。现有两阶段生成仍较慢，不能据这三次测试认定延迟或长篇一致性已完全解决。
- 已保存的旧正文和旧事实记录保留原样；叙事与资料提取规则改进作用于之后的生成，不会静默改写既有剧情。
