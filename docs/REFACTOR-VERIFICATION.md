## 真实模型接口

通过 `node scripts/verify-refactor.mjs` 显式调用本机 Codex + gpt-6-astra，记录原输入、输出、状态码和实际耗时于 `test-results/refactor-live.json`（开发资料，不发布）。

| 流程 | 实际结果 | 本次耗时 |
|---|---|---|
| 假设问答 | 返回可能性与不确定性；测试会话未改变 | 14.8秒 |
| 表达辅助 | 返回可编辑文字；测试会话未改变 | 12.7秒 |
| 自由行动 | 返回正文与有效事件，成功提交 | 28.2秒 |
| 润色 | 返回替换正文，应用后状态和事件完全相同 | 13.6秒 |
| 纠错 | 针对人为构造的越权错误返回修复提案；新分支可通过完整存档验证 | 21.7秒 |
| 一句话创建 | 返回有效茶铺世界，服务端分配标识；含角色前提与可玩开场 | 79.5秒 |

这些时间属于一次观测，不是速度承诺。纠错样本中的“强行成交和替人道歉”是测试故意构造的错误，不冒充模型实际发生的失败。

语义观察：含糊的“那个人”在送礼语境中被模型解读为顾客，而修复提案采用收礼人解释。这说明结构通过不能证明指代完全可靠。已补充一般性的对象/目标/禁止代价与重大歧义澄清规则；不声称该限制已彻底消除。

## 保留限制

### 主动叙事调整（2026-10-09）

用户反馈：需要世界主动推进，玩家进入经历，而非要求玩家持续编剧情。生成指令现要求承接行动后推进完整场景节拍；act/observe/delegate/skip 都允许人物与事件自行发展。平静故事可自然完成日常事务，不以危机和反转凑进展；假设问答仍不推进，重大玩家承诺仍不代选。输入区提供「读下一段」。

显式真实模型对照：`node scripts/verify-story-momentum.mjs before` 和 `after`。旧版对“不说话，看看接下来”增加一条信息后回到众人等待；新版两轮中人物主动说明来意、发送道歉消息、决定暂不买茶、完成清点并离开，店主未被替代签收、成交或承诺。详见 test-results/momentum-before.json 与 momentum-after.json。单次样本说明方向改善，不证明所有故事持续稳定。

浏览器独立测试存储中的雾港样例，点击「读下一段」后人物主动取出便条和包纸，产生新线索；未发送草稿原样保留。没有改动用户的生化危机存档。自动化82项通过，后台服务已加载新规则。

意图检测为保守规则提示，用户可显式选择用途；普通复杂表达仍依赖模型。记忆使用词语匹配与来源记录，不是向量检索或无限记忆。润色在结构上固定状态，语义事实仍需审阅。当前不支持多标签并发写入协调，使用同一浏览器单个活动故事页面。模型在远端运行，生成资料会发送给模型服务；本机授权不代表离线推理。
