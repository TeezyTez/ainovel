# 方糖 UI 优化与验收（2026-10-12）

本次修改现有前端，保留原有模型调用、世界状态、分支和存档机制。没有重新生成或替换历史正文，也没有创建演示剧情冒充生成结果。

## 实际改动

- 新增统一界面样式 `src/interface.css`：暖白 / 夜读主题、低饱和绿色强调、统一按钮和输入控件、卡片、弹窗、阅读排版以及移动端布局。正文的字号、字体、行距、宽度仍遵循用户偏好。
- 首页保留一个世界输入框，移除重复欢迎标题和额外整屏高度；继续阅读与开局库接在输入区后。
- 阅读页继续保留一个输入框。输入区的“＋ 工具”打开原生 popover，提供地图、状态、物品、人物、时间线、线索；另有搜索回顾、有限时间安排和继续阅读入口。
- 资料查看使用当前分支的公开投影。时间线读取已保存回合的正文摘录和已有时间标签，不推算日期。没有对应资料时显示明确空状态，并提供搜索入口。
- 右上角故事选项集中放置阅读设置、分支存档、书签、搜索、正文导出和帮助；修改剧情等低频操作放进折叠区。
- 阅读设置使用紧凑布局，将输入选项和叙述偏好折叠。书架 / 发现页的低频筛选折叠，原有搜索和筛选字段保留。
- 创作页区分“直接进入”和“生成草案”，手填和资料导入收进其他创作方式；世界设定展开后才显示保存 / 预览操作。
- 设置分类变成可用的页内跳转。修复直接刷新创作页后，模型连接成功却未启用“直接进入故事”的问题。
- 输入区从 sticky 改为 fixed，避免点击输入区把阅读位置拉到文末。ResizeObserver 跟踪输入区高度，工具面板避让输入；空草稿禁用发送。
- 弹窗添加可访问标题，关闭后返回可见的原入口。移动端普通保存状态收起，但保存失败仍保持可见。

参考了 [ChatGPT Canvas 官方介绍](https://openai.com/index/introducing-canvas/)中的上下文操作和快捷菜单思路：保留主要内容空间，在需要时展开工具。本项目的具体布局、配色和入口按小说阅读场景设计。

## 验收范围与限制

- 本次没有调用真实模型生成新故事，不能将 UI 测试等同于新一轮剧情质量验收。
- 旧故事缺少已记录的人物、物品、状态等结构化资料时，仍然会显示空状态。此次没有通过猜测补全这些资料。
- 手机检查使用浏览器视口模拟；未在实体手机及其软键盘上逐一测试。已接入现有 visualViewport 偏移逻辑，仍需真实设备验证。
- 继续使用本机存档与本机模型授权，没有增加云同步、支付或社区功能。
