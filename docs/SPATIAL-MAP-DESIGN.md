# 剧情驱动的空间地图

目标：地图反映持续存在的物理空间，不随当前卡片、玩家所在节点或刷新重新排列地理。沿用现有事件提交、分支快照与公开资料查询，不引入地图服务或图像模型。

## 设计

- 在 game 中增加可选 spatial 增量。sites 记录 place 的地貌、归属区域；relations 区分方位与实际道路，保存方位、距离、道路通行性、双向性及正文证据。
- 空间记录与瞬时 surfaces 分离，随回合合并保存。地点归属及既有方位不能被随意覆盖；道路开放、封锁可由新剧情证据更新。检查归属循环、未知地点引用、方位循环、确切测距矛盾。回放、分支、导出使用原有状态机制。
- 模型先承接已知空间约束，再写自然剧情并提交对应记录。证据必须来自公开正文，不能借地图泄露隐藏地点。旧结构仍可读取。
- SVG 根据约束投影地图：北向、可辨识地貌与建筑符号、路段、阻断标志、当前位置、比例或非等比例说明。只有全部测距确定的连通分量使用比例；未知距离不伪装测绘。地点归属作为可切换的区域/室内层级，不把房间与城市混在一个尺度。
- 缺少方位的地点放在“尚未定位”里；已知拓扑仍可查阅，不推断地图上左右等于世界方位。查询可从公开原句保守提取明确的命名方位关系，不改写旧存档。

## 实施与验收

1. 先测试空间更新、持久化、冲突、分支回放和旧格式兼容，再实现空间模块及生成协议。
2. 测试投影的方位/比例、当前地点变化不影响布局、室内分层、未知区域与恶意内容转义；实现 SVG、缩放和区域切换。
3. 用明确标注的剧情测试样例进行桌面/手机浏览器验收，再运行全量测试。测试样例不写入用户存档，不称为真实模型生成。

边界：任意自然语言语义无法用局部验证器完全证明；地图不能还原正文未提供的真实海岸线或建筑轮廓。符号表示地貌类别，边界未测量时不画精确轮廓。完整模型质量需另以真实生成验证。

距离投影先检查路径距离上界（三角不等式）、方位循环和精确轴向距离，再求刚性分量、圆交点及其余数值约束。东北等斜向表示象限，不强制 45 度。数值求解未收敛不等于世界不可能：保留已记录事实，降为明确标注的方位示意，不显示比例尺。当前并非一般二维距离图可满足性的完整证明器。
