# 从《蜘蛛侠：多元宇宙》到 elselife 的美术方向

研究日期：2026-10-14。目标：为互动小说网页提炼主题、配色与构图方法。下面将制作事实与本项目的设计判断分开；色值均为网页提案，并非影片官方色板。

## 设计结论

建议把首页想象成一本正在展开的多世界漫画：每个世界拥有自己的材料、色彩和秩序，而“由你决定故事”是把它们连起来的主题。首页需要一个明确的阅读顺序：标题 → 世界画面 → 进入动作。中部的联系应由同一个构图建立，不靠补充更多宣传文字填空。

## 六条可核实的美术原则

| 原则 | 来源事实 | 网页迁移建议（本项目判断） |
| --- | --- | --- |
| 1. 先确定世界的视觉语法 | Sony 将 Gwen 描述为水彩世界，将 Vulture 描述为手绘的活画；Hawkins 在原始采访中说明不同角色有各自的渲染与运动语言。[Sony 制作专题](https://www.sony.com/en/brand/beyondthescreen/acrossthespiderverse/)、[Hawkins 采访](https://beforesandafters.com/2023/06/17/the-across-the-spider-verse-spider-punk-character-hobie-was-animated-with-different-frame-rates-for-different-parts-of-his-own-body-and-accessories/) | 给都市、幻想、未来等世界分别选择墨线印刷、水彩、几何光片等材料。在同一个首页中并置三种世界，让“多元”可以直接看见。 |
| 2. 强形状承载构图，纹理提供材料感 | Imageworks 官方说明第一部强调图形、鲜明色彩、强构图与简化设计，用网点和排线表现漫画印刷，而非完全依赖平滑渐变。[Imageworks 美术拆解](https://www.imageworks.com/our-craft/feature-animation/movies/spider-man-spider-verse) | 保持标题、按钮和卡片轮廓清楚；网点只放在世界画面的局部阴影、背景边角。阅读正文使用安静的底色。 |
| 3. 套印偏移有明确的视觉用途 | 第一部用印刷套位误差启发景深表现；第二部的合成团队制作了模拟 CMYK 印刷与套色偏移的工具。[Imageworks](https://www.imageworks.com/our-craft/feature-animation/movies/spider-man-spider-verse)、[Foundry 对 Imageworks 合成主管的采访](https://www.foundry.com/insights/film-tv/across-the-spider-verse-nuke-mari-katana) | 青色与玫红可作为两条轻微错位的边缘，用于主视觉框、选中态或大标题重点词；正文和操作文字保持单色清晰。 |
| 4. 色彩能够表达情绪 | Sony 官方说明 Gwen 的水彩背景流动、渗染，并反映她的情绪。[Sony 制作专题](https://www.sony.com/en/brand/beyondthescreen/acrossthespiderverse/) | 浅色主题以纸白承接淡青与粉紫；色彩集中在世界图与局部气氛，保留足够空白。将来可根据故事情绪改变画面色调，而非随机轮播颜色。 |
| 5. 不规整要有角色理由 | Hawkins 描述 Hobie 的视觉来自独立刊物、复印与拼贴，其不同部件使用不同运动节奏。[Hawkins 原始采访](https://beforesandafters.com/2023/06/17/the-across-the-spider-verse-spider-punk-character-hobie-was-animated-with-different-frame-rates-for-different-parts-of-his-own-body-and-accessories/) | 用少量裁切边、叠纸、斜切标签表达“选择可改写命运”。不把导航、输入框和所有内容卡都倾斜；稳定操作区仍遵守栅格。 |
| 6. 多样性仍需要注意力控制 | Hawkins 特别强调控制 Hobie 在单个镜头内的风格变化，避免每次运动都抢走注意力。[Hawkins 原始采访](https://beforesandafters.com/2023/06/17/the-across-the-spider-verse-spider-punk-character-hobie-was-animated-with-different-frame-rates-for-different-parts-of-his-own-body-and-accessories/) | 首屏只保留一个视觉重心；彩色世界画面负责吸引，按钮负责引导。动画在选择、悬停和切换时发生，静置时让页面安静。 |

## 首页构图建议

建立一个共同的横向画幅：左侧标题和右侧世界图共享背景与底部基线。右侧用三张彼此部分遮叠的世界切片组成同一个画面，最近的一张占主导，其余两张只露出不同色彩与材质。让最靠近标题的一条裁切边、色带或短连线跨入两者之间，形成视觉接续。

这能回应此前“标语与图片之间空、但挪近仍不舒服”的反馈：问题可能不只是间距，两个物件缺少共同的构图关系。需在实际桌面与手机视口中验证此判断。世界切片不能与正文重叠；窄屏改为标题在上、同一组世界图在下，保留完整可点击区域。

主标题可围绕“一个选择，另一个你”或“每个选择，都有另一个世界”表达；这是本项目原创文案候选，不是影片台词。世界名称、进入动作与故事内容比装饰性技术编号更有价值。

## 配色提案

| 角色 | 浅色主题 | 深色主题 | 使用位置 |
| --- | --- | --- | --- |
| 纸面 / 夜幕 | `#F8F4EE` | `#131321` | 大面积背景 |
| 墨色 / 纸白 | `#242238` | `#F5F1E9` | 标题与正文 |
| 玫红 | `#C82D69` | `#FF73AB` | 主行动、重要选择 |
| 青蓝 | `#087E96` | `#6EDAE9` | 另一世界、套印边缘 |
| 淡粉紫 | `#EBDCEF` | `#45334F` | 水彩世界、情绪背景 |
| 暖黄 | `#F2C45B` | `#F2C45B` | 少量路标与点睛 |

浅色可以获得“有颜色的纸本漫画”感，深色可以获得“彩色油墨从夜幕透出”感。不要把浅色实现为所有深色值的机械反转。每个世界宜以一组主色和一种材质建立身份，整页同时出现的高饱和大色块应有限。

这些色值只定义方向；落地时需对实际文字/背景组合验对比度，并查看透明叠层后的结果。纹理不能影响阅读，动效须尊重减少动态偏好。

## 本轮适合落地的范围

1. 首页主视觉改为三种世界材料的并置，并让标题与画面共享构图。
2. 深浅主题采用同一组玫红、青蓝、纸色角色，分别调整明度与面积。
3. 世界入口应用清晰的色彩身份；用细小套印边和局部网点统一语言。
4. 保留阅读页的稳定排版；不添加常驻故障闪烁、持续漂移或全屏纹理。

本研究没有发现可直接采用的影片官方十六进制色板；也未将 Miguel 世界归纳为任何未经核实的官方配色规则。

## 用户反馈后的实际实现（2026-10-14）

用户认可虫洞配色，否定将洋红、青、黄铺进界面的方案。最终方向是：保持黑白主体，在少量细节上体现绚丽的多色感。上文配色表保留为研究提案，不是当前界面规范。

- 保留已调整的居中双栏与多节点虫洞，以及两套主题下的虫洞渐变、网格和节点色相。
- 浅色背景 `#F7F7F7`、正文 `#232326`、次文 `#68686D`、按钮 `#252528`；深色恢复近黑背景与灰白文字、按钮。
- 移除彩色标题、黄色下划线、漫画硬阴影、卡片彩边与新增封面纹理。封面图片保持原样。
- 仅品牌小图标和导航选中细线使用柔和的紫、青、绿、金、粉虹彩；品牌文字、标题、控件和内容边框保持中性。
- 界面样式在 `src/multiverse.css`；虫洞与细节配色在 `src/portal-palette.css`；几何插画在 `src/multiverse-art.js`。
- 阅读器保留自身配色，原有减少动态与高对比度适配继续生效。
