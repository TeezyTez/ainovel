# 主动情景界面验收 · 2026-10-10

## 实际改动

- 生成协议按当前空间、时间、人物、资源和决策的信息需要选择界面；地图不再必须带行动按钮才能主动显示。
- 新增 timeline、people、comparison 三种声明式界面，沿用既有状态校验、提交及存档机制。
- `src/adaptive-surfaces.js` 从已提交的公开记录补充状态变化、时间安排、人物、比较和已知路线展示；不调用模型、不改世界、不创造行动。
- 阅读区最多自动展开两张相关卡片，重复和历史内容折叠；用户的纯阅读密度设置仍有效。手动折叠状态在本页面的局部刷新期间保留。
- 时间线区分预定与实际；定性状态不伪造数值条；人物不伪造关系；地图不猜测距离、用时或安全性。可展开原文依据。
- 地图首次显示和展开时定位到当前位置，保留用户后续平移。继续使用一个输入框。

## 边界与未解决事项

- 界面由受校验的九种类型组合呈现，不执行模型生成的任意 HTML。开放情景的选择主要依赖模型判断，两个真实样本不能证明所有情景都能选择最佳表达。
- 旧故事只有散文、没有结构化事实的内容不会自动补造成记录。地图补充只复用上轮已有连接，不推断新路。
- 折叠偏好目前只在页面生命周期内保留，完整重载后重新执行展示策略。
- 验收故事开场散文写了下午三点，但初始结构化时钟为空，页眉仍显示“故事时间未说明”。本次没有从散文猜测并回填时钟。
