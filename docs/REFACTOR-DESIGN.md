# 此间 · 处境与意图重构

依据：桌面《纯文字AI互动世界_核心产品方案_重构版_2026-10-09.md》。用户明确授权直接重构现有原型。本文将首版体验落实为本机可运行变更，不将商业建议或概念样例视为已验证结论。

## 目标与范围
让玩家直接进入有参与理由的处境，或由一句设想生成可审阅的开局；行动、假设询问、辅助表达、润色和纠错分开处理。支持阅读、细致行动和有限委托；回到故事时恢复局面、公开事实和未发送方向。完成、保留与另试一种可能同样是有效结果。

继续采用原生 JS/CSS + Node HTTP + localStorage，复用本机 Codex。旧 schemaVersion 1 存档必须可加载，新增字段可选。现有世界版本不静默替换，原有故事/分支/正文不删除。没有数据库迁移或公开部署。

## 模块接口
- `src/experience.js`：纯函数。intent 分类提示、公开回顾、相关历史选择、表达修订应用、带来源记录。不得将辅助结果直接提交为回合。
- `src/server-workflows.mjs`：辅助模型流程。POST `/api/assist` 输入 `{requestId,kind:'world'|'ask'|'phrase'|'polish'|'repair',seed? ,world?,state?,player?,preferences?,memory?,recent?,input,target?}`；输出 world 草案或 `{requestId,kind,text,...}`。只在服务器选定模式、schema 与指令。问答仅传公开资料。润色仅返回正文，无事件。纠错返回修订正文与事件提案，用户审阅后才在新分支提交。
- `src/server-codex.mjs`：可传专用 schema，保留安全 CLI 边界。
- `src/app.js` / `src/style.css`：处境首页、轻创作、参与方式、回顾、辅助结果审阅、三种重来、满意结束。
- `src/worlds.js`：新增可选体验元数据与真实模型茶铺样例，保留旧预设原内容与演示。

## 核心约束
- 故事状态只通过结构化事件提交；问答、表达帮助和润色不推进时间。
- 系统纠错从最后一轮之前建立明确标注的修复分支；原结果保留，不能自动编造事实来源。
- 润色只更新最后一轮的表达，保存原文修订记录，保留 input/events/state/事实/建议；旧记忆文本与正文同步。结构上不允许润色改变事件，但语义仍需用户审阅。
- 自由输入中明显假设问题或作者操作先路由到相应辅助入口，不误执行；提供可见模式与改为行动的出口。分类只是保守提示，不冒充完美意图识别。
- 阅读/略过/委托只影响本轮叙事授权，不允许隐含接受重大承诺。
- 公开回顾来自已提交公开记录，不泄露 hidden/secret；不模拟现实离线时间。
- 相关历史选择包含早期相关事件 + 近期记录，来源和分支保持；没有无限记忆保证。
- 无真实模型时轻创作明确可手填，不能把固定模板声称为 AI。

## 验证
自动测试：辅助调用不提交状态、润色事件不可变、修复分支无未来状态、早期相关记忆、公开回顾无泄密、旧存档兼容、取消/超时。
真实调用：一句话茶铺、假设询问、自由行动、润色、纠错至少各一条结果；记录失败而非只保留成功。
浏览器：首屏处境、轻创作审阅后开局、模型辅助不推进回合、真实行动保存、返回回顾、移动端宽度与输入。
未纳入：付费/公开社区/云同步/无限 NPC 模拟/完整人物信念引擎。无商业验证结论。
