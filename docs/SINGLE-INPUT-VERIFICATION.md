# 单输入框改动与验收（2026-10-10）

阅读页常驻输入区只保留一个自动增高的输入框与内嵌发送键。移除继续、接管、资料、时间、经历、设置、模式选择、建议、密度和展开输入等常驻控件。人物链接、剧情内的按需信息与历史记录仍保留。结局后仍可输入查询。

输入自动路由；旧存档的手动输入模式不再影响发送。新增“继续”“重试”“恢复进度”“查看存档”“故事选项”“保存为…”等精确指令。明确的等待输入携带有限时间授权与完整原文；不将引号对白、假设问题当作时间推进授权。发送位置在生成期间变为停止键，能取消剧情或辅助生成。

## 实际验证

- Node 完整测试：243/243 通过，输出见 `test-results/single-input-tests.txt`。
- 浏览器真实存档：海风里的修伞铺。在 V1 输入“我有哪些物品？”显示旧蓝布伞资料，回合和时间未变。
- 同一输入框发送“等到午休，阿苇回来就停，不替我报价或接单，不花钱。”，本机 Codex 真实生成并提交第 2 回合（`348d99f0-4024-4e8a-8bc6-9526c25a3b12`）。时间到周二午休，阿苇返回；报价、接单、材料与铜钱均未改变。在商谈前交回控制。
- 生成期间输入另一份草稿，返回后草稿仍在；发送键恢复可用。清空测试草稿后刷新，第 2 回合与午休状态仍在。
- 390 × 844 移动端预览：文档宽度与滚动宽度同为 375，没有横向溢出；输入区约 78px 高，只有一个文本输入，无模式下拉框。

## 范围与限制

简化的是常驻阅读操作区。明确请求高级工具时，仍按需打开既有面板；没有删除存档、历史、引用等有效能力。自然表达沿用既有保守意图识别与模型处理，不宣称能无误理解任何句式。生成耗时未在本次优化。
